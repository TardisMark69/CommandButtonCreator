Command Button Creator - Updated Version

New features:
1. The main window can be freely resized.
2. The command-button canvas is inside a scrollable area.
3. Horizontal and vertical scroll bars appear automatically when needed.
4. The canvas grows automatically when buttons are moved or resized farther right or down.
5. Ctrl+click selects or deselects multiple command buttons.
6. Selected buttons have a gold outline.
7. Dragging the resize handle of a selected button resizes all selected buttons together.
8. Make All Same Size resizes all command buttons to the largest current width and height.
9. Clicking empty canvas space clears the selection.
10. Button positions, sizes, labels, and commands are saved automatically in buttons.json.

Replace the files in the project working directory with the complete files supplied here.
